## 0. この実験の性質（最重要・冒頭明記／境界条件の織り込み）

**本検証は「探索的・非採用前提」の予備調査であり、その結果はいかなる場合も本番採用（production / D統合反映）の判断材料にしない。**（境界条件①）。良い数字が出ても採用プロセスには進めない。D統合反映官の起動条件（採用＋司令塔GO）に本探索の結果は**そもそも入力されない**。

本探索が答える問いはただ一つ:
> **「クロスセクション・モメンタムというアイデアに、生存バイアスありのBitget現行銘柄データでも、全く芽がないか／何かしら示唆があるか」を安価に覗く。**

この予備調査は**非対称**である（S決定メモ §1）: 生存バイアスは既知の方向（上振れ）に効くため、「示唆あり」でも過大評価であり、**「芽なし」の方が情報価値が高い**。「示唆あり」は有料データ投資（選択肢A）の事前確率をわずかに上げる**参考情報**に留まり、採用根拠にはならない。

### 本specに常時かかる4つの絶対的境界条件（S決定メモ §3。逸脱は本探索を無効化する）
1. **本番採用の判断材料にしない**（上記）。
2. **生存バイアスを全結果に付記**（境界条件②）。すべてのグラフ・表・要約数値に「**生存バイアス上振れ・非採用前提・現行生存銘柄のみ（死銘柄除外）・N=14〜50**」の注記を同伴させる。バイアス開示なしの単独のSharpe/リターン/IC表示を一切させない（§7でB実装官に明示）。
3. **正式ゲート（G1-G4）を適用しない**（境界条件③）。OBS000029等で使ったPASS/FAIL採否基準は本探索に適用しない。出力は合否判定ではなく**記述的な観察**（横断ICの符号・大きさ・held-out銘柄再現の有無・レジーム別挙動）に留める。§5の「観察読み取りルーブリック」は採否ゲートではなく、HARKing防止のため読み方を事前固定するだけの記述的指針である（回す前に確定・後付け禁止）。
4. **ポジティブでも採用プロセスに進めない**（境界条件④）。示唆が出ても「有料データ投資を検討する価値があるか」の参考に留め、Stage 2/3・D統合反映には進めない。進める場合は必ず**有料データ基盤（死銘柄履歴＋上場/廃止台帳＋Funding長期履歴）整備後に、サバイバーシップ排除済みの横断バックテストを別OBSとして再起票**する。本探索結果は再起票時の「事前確率の参考」以上の重みを持たない。

## 2. 対象ユニバースの定義（固定）

**Stage 0 で取得済みの `research/EXP-OBS000030/10-result/history-*.json`（50銘柄・日足OHLCV）を唯一の価格ソースとする。新規のAPI取得は不要**（Funding長期履歴は無料APIで不成立確定のため本探索では価格のみ）。全銘柄が「現行生存銘柄」であり死銘柄を含まない＝生存バイアスあり（境界条件②を全出力に付記）。

深さ×幅トレードオフ（C最終判定 §2）を**設計上そのまま観察に落とす**ため、以下**2つのユニバース構成を並行して測定**する。Nの扱いはA設計判断として「①14本固定（深・狭）」と「②PIT可変N（浅・広）」の両方を採る（片方に決め打たない。両者の差自体が深さ×幅の観察対象）。

### Config A ＝ 固定N・深い（primary observation）
- **銘柄（14本固定・明示列挙）**: `AAVEUSDT, ADAUSDT, AVAXUSDT, BCHUSDT, BNBUSDT, BTCUSDT, DOGEUSDT, ETHUSDT, FILUSDT, LINKUSDT, NEARUSDT, SOLUSDT, XLMUSDT, XRPUSDT`
  - 根拠: G0-1実測（`G0-1-history-depth-analysis-v2.json`）で `covers3YearsFrom=YES` かつ `covers2022FullYear=true` の**14本**。全期間を通じて存在し、**2022年通年（BTC弱気・総崩れレジーム）を含む**唯一の構成。横断モメンタムの核心的弱点（トレンド反転/ローテーション局面での挙動）を観察できるのはこの構成のみ。
  - N=14固定。横断LSの最小ブレッド帯（S memo が明記する「3年ライン到達14本」）。
- **測定期間**: **2022-01-01 〜 2026-07-02**（各history-*.jsonの共通最古以降。2022通年＝弱気を必ず含む）。
- **性質**: 深いが狭い。かつ「2022時点で存在した14銘柄＝現行まで生存した銘柄」なので**生存バイアスが最も強い**（2021-2022に上場廃止された当時の上位銘柄が完全に欠落）。付記必須。

### Config B ＝ 可変N・PIT（secondary observation）
- **母集団**: `history-*.json` の全50銘柄。
- **PIT組入れルール（先読み排除・G0-3プロトタイプ流用）**: 各月次リバランス日 `t` において、**`t` 時点で日足が `L+観測最小 = 30+30 = 60本以上` 存在する銘柄のみ**を母集団に含める（`t`以降のデータ・将来の上場/廃止を一切参照しない）。`scripts/pit-universe-prototype-v2.ts` のas-of `candles.filter(c => c.date <= rbDate)` ロジックをそのまま踏襲。
- **N の扱い**: 上記ルールで**時期により可変**（実測では2022付近≈14 → 2026付近≈50。C最終判定の「幅を増やすと深さが減る」を1つの構成内で顕在化させる）。各リバランスの実N・銘柄一覧を出力必須。
- **測定期間**: **2022-01-01 〜 2026-07-02**、月次リバランス。
- **性質**: 幅は広がるが各時点で新規上場銘柄は履歴が浅く、かつ**やはり現行生存銘柄のみ**（PIT組入れ判定は「現存する銘柄が過去にデータを持っていたか」で行い、当時存在して既に消えた死銘柄は物理的に含められない）＝生存バイアスは解消されない。付記必須。

> **NのA設計判断の記録**: 「14本固定 vs PIT可変」のどちらか一方に決め打たず両方を測る。理由＝本探索の主目的が「深さ×幅トレードオフ下で芽があるか」の記述であり、Config Aで深さ（弱気レジーム含む）、Config Bで幅（横断分散が効くか）を各々観察し、両者が整合するかを見ることが最も情報量が高い。**主観察はConfig A**（レジーム被覆が判断に不可欠なため）、Config Bは補助。

## 3. シグナル定義（固定・②のL=30系を流用し新規探索を最小化）

### 3-1. ルックバックと横断ランク
- **ルックバック L=30日**（②本番モメンタムの本番値を流用。**単一値で事前固定**。複数Lグリッド探索はしない＝多重検定を作らない）。
  - 参考感度として L∈{15, 60} を**併記のみ**許可（読み方は§5で L=30 を唯一のprimaryと事前宣言済み。L=15/60は記述的な感度確認であって選定対象ではない）。
- **横断モメンタム・シグナル**: 各リバランス日 `t` で、対象ユニバース内の各銘柄 `i` について直近リターン `mom_i = close_i[t] / close_i[t-L] - 1` を計算し、**その日のユニバース内で横断ランク付け**する。
- **時系列モメンタム（②）との違いを保持**: ②は「自分の過去に対する符号」だが本件は「同時点の他銘柄に対する相対順位」。測る軸が直交する（prescreen §想定エッジ）。

### 3-2. ポートフォリオ構築（ドルニュートラルLS）
- **リバランス頻度**: **月次**（各月初、Config A/B共通。PIT機構と整合。②のHORIZON=10日ではなく月次に固定＝ターンオーバー/コストを抑えた横断LSの標準設定）。
- **保有期間**: リバランス間（1ヶ月）保有。
- **建玉**: 横断ランク上位 `k` 本をロング、下位 `k` 本をショート。`k = max(1, round(N/3))`（テルシル。N=14なら k=5、N=30なら k=10、N=50なら k=17）。各レッグ内は等ウェイト。
- **ドルニュートラル**: ロング総額＝ショート総額。グロスエクスポージャを1に正規化（ロング0.5/ショート0.5）。市場βを抜く。
- 中位（ロングでもショートでもない）銘柄は建てない。

### 3-3. 執行コスト（Bitget実値志向・非採用前提でも芽を正直に見るため織り込む／S memo §4）
- **取引コスト（往復・リバランス毎のターンオーバーに課金）**: `コスト = テイカー手数料 + スリッページ`。
  - テイカー手数料: **6 bps/片側**（Bitget USDT-perp標準テイカー水準。B実装官はBitget公開の手数料表で裏取りし、乖離があれば実値を採用し注記）。
  - スリッページ（流動性階層別・`snapshot-tickers-top50.json` の24h USDT出来高ランクで区分）: **ランク1〜10 = 5 bps/片側、11〜30 = 15 bps/片側、31位以下 = 30 bps/片側**。
  - 各月次リバランスで、ウェイト変化（ターンオーバー）× 上記片側コスト × 2（往復相当）を控除。
- **Funding コストの扱い**: 3年Funding履歴は無料APIで不成立（`21-verdict-stage0-final.md` §4、平均72日・最大90日で枯渇）。よって**全期間ネットにFundingは含めない**。これは**ショートレッグの保有コストを過小評価する方向のバイアス**であり、その旨を全ネット数値に注記する（捏造しない・欠損を正直に開示）。
  - 補助として、Fundingが存在する直近≤90日についてのみ、Funding込みネットを**別枠・部分期間限定**で参考併記してよい（primaryではない・明示ラベル必須）。
- **必ずグロス（コスト前）とネット（コスト後）の両方を全構成・全レジームで報告**（コスト前だけで芽が見えても無意味／S memo §4）。

## 4. 測定範囲と「予測単位＋パイプライン両方」の必須測定

**予測単位（cross-sectional IC）とパイプライン統合（LSポートフォリオ）の両方を必ず測る**（片方だけは禁止。過去、予測単位◎でもパイプラインで死ぬ罠が頻発）。

### 4-1. 予測単位＝横断IC（cross-sectional Information Coefficient）
- 各リバランス日 `t` で、ユニバース内の `{mom_i}`（シグナル）と `{forwardRet_i = close_i[t+1M]/close_i[t] - 1}`（翌1ヶ月フォワードリターン）の**横断スピアマン順位相関 IC_t** を計算。
- 報告: **平均IC、IC標準誤差、IC t値（= 平均IC / (IC標準偏差/√期間数)）、IC>0の月の割合、permutation p値**。
- **permutation（事前固定）**: 各リバランス日内でフォワードリターンを銘柄間シャッフルし平均ICの帰無分布を生成（N_PERM=5000、seed固定、`momentum-robustness.ts` の mulberry32 と Fisher-Yates を流用）。観測平均IC以上が出る割合を p とする。

### 4-2. パイプライン統合＝ドルニュートラルLSポートフォリオ
- §3-2の月次LS戦略のエクイティカーブを構築。
- 報告: **グロス／ネット双方の 年率Sharpe、累積リターン、最大DD、月次リターン系列**。Sharpe年率化は月次のため `√12`。
- **portfolio permutation（事前固定）**: 月次ポジション符号を保持しフォワードリターンをシャッフルして帰無Sharpe/リターン分布を生成（同seed規約）、観測値の p を報告。

### 4-3. selection / confirmation プロトコル（過学習の炙り出し・2軸）
正式ゲートは使わないが「芽が本物か過学習か」を炙り出す最低限の分離は維持する（S memo「最低限の統計的厳密さ」）。**分割は回す前に以下で確定済み（後付け禁止）**。

- **(A) held-out 銘柄分割**（Config Aの14銘柄をアルファベット順・奇数/偶数indexで2群に事前固定）:
  - 選定群（odd index 1,3,…13）: `AAVEUSDT, AVAXUSDT, BNBUSDT, DOGEUSDT, FILUSDT, NEARUSDT, XLMUSDT`（7本）
  - 確認群（even index 2,4,…14）: `ADAUSDT, BCHUSDT, BTCUSDT, ETHUSDT, LINKUSDT, SOLUSDT, XRPUSDT`（7本）
  - 各群内で**群内横断ランク・群内IC**を独立に計算し、**確認群（held-out銘柄）で選定群と同符号・同程度のICが再現するか**を観察。N=7は低パワーである旨を明記（記述的観察）。
- **(B) 時系列分割**（期間を事前固定）:
  - 選定期間: 2022-01-01〜2024-06-30、確認期間: 2024-07-01〜2026-07-02。
  - 確認期間で選定期間と同符号のIC/ポートフォリオ挙動が再現するかを観察。

### 4-4. レジーム別分解（要）
Config A（14銘柄）について、以下3レジームで IC とポートフォリオ（グロス/ネット）を**分解して報告**（横断モメンタムは相対トレンド持続局面で機能し反転局面でDD＝prescreen §レジーム依存性）:
- **R1 弱気/総崩れ**: 2022-01-01〜2022-12-31
- **R2 回復**: 2023-01-01〜2024-12-31
- **R3 直近**: 2025-01-01〜2026-07-02

## 5. 観察読み取りルーブリック（**採否ゲートではない**・HARKing防止のため読み方を事前固定）

以下は境界条件③に従い**PASS/FAILの採否判定ではない**。回す前に「どういう結果を芽なし/弱い示唆と記述するか」を固定し、結果を見てからの物語作り（HARKing）を封じるためだけの記述的指針である。判定はしない。**どの結論でも採用プロセスには進めない**（境界条件④）。

- **記述①「芽なし」（＝有料データ投資の事前確率を上げない・情報価値が高い側）**: 次のいずれかに該当。
  - Config A の全ユニバース平均IC ≤ 0、または permutation p ≥ 0.10、または
  - held-out銘柄（確認群）のIC符号が選定群と一致しない、または
  - ネット（コスト後）ポートフォリオSharpe ≤ 0。
- **記述②「弱い示唆」（＝有料データ投資検討の参考事前確率をわずかに上げるのみ・採用ではない）**: 以下を**すべて**満たす。
  - Config A 全ユニバース平均IC > 0 かつ permutation p < 0.05、かつ
  - held-out銘柄（確認群）でIC符号が選定群と一致（同符号）、かつ
  - ネット（コスト後）ポートフォリオSharpe > 0 が R1〜R3の**3レジーム中2つ以上**で成立。
- **記述③「混在/保留」**: 上記①②のいずれにも明確に該当しない → 記述のみ（芽の有無を断定しない）。

**注記（全結論に付す）**: 生存バイアス上振れ前提のため「弱い示唆」でも過大評価。「芽なし」の方が情報価値が高い非対称予備調査（S memo §1）。いずれの記述も採否ではなく、有料データ整備後の別OBS再起票時の事前確率の参考に留まる。
