## 【最重要】§2 vs §6 の Sharpe 乖離 — 原因特定（オーケストレーター論点への回答）

オーケストレーターが発見した矛盾:
- **§2 SC-2**: 実測コスト後の確認期間 Sharpe(√52) = **+2.376**（強くプラス）
- **§6 `sleeveMetrics_confirmationPeriod.vrp`**: 確認期間 Sharpe(√365) = **+0.0107**（ほぼゼロ）・cumReturn = **−0.0849%**（わずかにマイナス）

同一戦略・同一確認期間で「強いエッジ」と「ほぼノイズ」の両立不能な2結論。**C検証の結論＝オーケストレーターの仮説は正しい。原因は spec §5-1 の `pnl_vrp` 定義（VRP水準の1階差分）である。**

### 1. `pnl_vrp` は望遠鏡和（telescoping）で平均ゼロのノイズになる — 恒等式で証明

spec §5-1: `pnl_vrp_t = vegaNotionalPct × (VRP_daily_t − VRP_daily_{t-1})`。これは**水準系列の1階差分**である。1階差分系列の総和は隣接項が相殺し、**始点と終点の差だけ**が残る（telescoping）:

```
Σ_{t} pnl_vrp_t = vegaNotionalPct × (VRP_daily_end − VRP_daily_start)
```

すなわち累積は「期間中に実際に収穫したプレミアム」ではなく「VRP水準が期間全体で正味どれだけ動いたか」しか表さない。VRP水準は持続的だが有界（平均回帰的）ゆえ、始点終点差は小さく、平均はほぼゼロになる。

**C独立検算（`stage2-vrp-tail-correlation-pnl.json` の `pnlVrpDailySeries` 実配列＋恒等式照合）**:

| 量 | 実測値（確認期間 n=1097） | 検算 |
|---|---|---|
| `pnl_vrp` 平均 | **+0.0001073 %/日** | ≒ゼロ（carry平均0.04065%/日の**約1/380**） |
| `pnl_vrp` std | 0.1922 %/日 | — |
| 算術累積 = 平均×n | +0.11772 % | telescoping帰結 |
| ボラティリティドラッグ = 0.5·σ²·n | −0.2026 % | 0.5×(0.001922)²×1097 |
| 複利累積 = 算術累積 − ドラッグ | −0.0849 % | **JSON値 −0.08486 と完全一致 ✓** |
| 含意する VRP水準の正味変化 = 算術累積/vegaNotionalPct | ≈ +5.86 vol pt（3年で微増） | telescoping逆算 |

複利累積が算術累積とドラッグの差に**桁まで一致**することが、この系列が1階差分（平均≒0）であることの決定的証拠。複利がわずかにマイナスなのは水準が下がったからではなく、単に**平均ゼロ系列にボラティリティドラッグがかかっただけ**である。

### 2. なぜ §2 と桁違いに乖離するのか — 別物を測っている

- **§2（正しい経済量）**: 週次に short-vol（ショート・ストラドル/バリアンス）を建て満期まで保有して収穫する `(VRP_t − C_real)`。これは毎週の実キャッシュフロー。確認期 平均 **6.461 vol pt/週** = 資本比 **0.1298%/週** = 日次相当 **0.01854%/日** = 157週で算術 ≈ +20%。VRPが平均 +9.3 vol pt（確認期）で構造的にプラスだから正。
- **§5-1/§6-1（`pnl_vrp`）**: VRPスプレッド水準の**日々の変化**。収穫プレミアム（週次に確定するtheta的なプレミアム減衰＝キャリー成分）を一切含まず、`ΔVRP` の平均回帰ノイズだけを拾う。

数値で言えば、真のVRP日次リターン（≈0.01854%/日）は `pnl_vrp` 平均（0.0001073%/日）の**約173倍**。**`pnl_vrp` は戦略の損益ではなく、戦略が保有するポジションの日次マーク・トゥ・マーケットの一次近似ですらない**（正しい short straddle の日次MtMは `−vega×ΔIV + theta + ...` で、収穫プレミアムに相当する theta/キャリー計上を含む。§5-1はこの計上を欠き、かつ符号も short-vol と逆の `+ΔVRP` を採る）。ただし符号の是非以前に、**1階差分ゆえ平均≒0という致命傷**が支配的である。

### 3. `pnl_vrp` は「相関の測定」には正しく、「合成のリターン」には誤り — 罪状の切り分け

spec §5-1 で `pnl_vrp` を採ったのは、Stage 1 でC自身が指摘した「VRP**水準**系列は自己相関が強く、日次リターンとの相関が構造的に低く出やすい（ゲートを通過しやすい方向のバイアス）」を是正するため（C申し送り(ii)）。**相関・共変動の測定に関しては、1階差分は正しい是正**である（自己相関を除去し、真の日次共変動を測る）。実際、差分系列でも |ρ| は 0.04〜0.05 と依然低く、**Stage 1 の低相関結論がバイアスの産物でなく本物**であることが確認された（G1-A1'・G3' はこの意味で有効に達成）。

**問題は §6-1 が、相関是正のために作った差分系列を、そのまま合成の「リターン系列」として再利用したこと**。相関に正しい系列（平均≒0の差分）が、リターン寄与の測定には誤り（平均を持たない）である、という取り違えが乖離の正体。**これは B実装の瑕疵ではなく spec §6-1 の設計問題**（B は §5-1・§6-1 の定義に忠実に実装している。後述コード確認で虚偽なし）。

### 4. G4' 判定への影響 — 「未達」は偽陰性・当てはめ無効

`composite3Sleeve` は VRPスリーブのリターンに `pnl_vrp`（平均≒0）を用いる。逆ボラ凍結ウェイトは VRP に **37.6%** を割り当てる（VRPの差分系列 std 0.192 が carry 0.180 と同オーダーのため）。結果、資本の約38%が**リターン≒ゼロのスリーブ**に配分され、単に分散だけ足して収益を足さない → 3スリーブSharpe 2.860 vs 2スリーブ 3.269、**sharpeDelta = −0.409**（G4'(a) 未達）、ddDelta −2.00pt（G4'(b) の −5pt 未達）。素朴等ウェイトでも sharpeDelta −0.150・ddDelta −1.547 で同様に未達。

**この「未達」は VRP の限界寄与が無いことを意味しない。** 経済的に正しいVRP日次リターン（真の収穫プレミアム）を合成に入れれば結論は反転しうる。**C試算（例示・要A/B本実装）**: `pnl_vrp` の std（0.192%/日）を保ったまま平均を真値（0.01854%/日）に置換すると、VRP日次Sharpe(√365) ≈ 0.01854/0.192×19.105 ≈ **1.84**。逆ボラ3スリーブ合成の推定Sharpe ≈ **4.0**（2スリーブ3.27比 **+0.7**）で **G4'(a) 通過側**に振れる。※この推定値は「週次payoffの日次分配法」に依存し（1日集中なら日次std増→Sharpe低下、均等分配なら平滑化→Sharpe過大）、**正確な数値はA再設計＋B再実装を要する**が、**符号が −0.41 から強くプラスへ反転すること自体は分配法に頑健**。よって **G4' の当てはめは現状無効**であり、これに基づく採否判断は下せない。
