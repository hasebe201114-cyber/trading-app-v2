## 対応OBS番号
**OBS000027（暫定・E記録進行官の採番で確定）**。親（再開元）: OBS000014「③LLM特徴量抽出層の実LLM化」。
本件は OBS000014 の続きだが、②の土台が k-NN → モメンタム(L=30, scale=30) に替わった後の**別条件での再決着**であり、新規実験1件＝新OBSとして扱う。

## 仮説（1文・falsifiable）
「③LLM特徴量層（claude-haiku-4-5, liveキャッシュ）を **新②（モメンタム L=30・確信度z値 scale=30）** の土台に、**現行④統合ロジック（veto+確信度加点+高ボラ縮小、mainのまま無改変）** で載せると、③なしに対しパイプラインの 5フォールド平均 Sharpe を +0.20 以上改善し、かつ改善フォールドが過半（≥3/5）を占める」。
→ これを満たさなければ仮説は棄却（③は現行構成では新②の上でも増分価値なし）。

## 検証する自由度（何を固定し、何を可変にするか）＝(a)/(b)の選択

**選択: (a) 単純版（現行④固定・自由度ゼロの再測定）を採用する。**

固定するもの（可変にしない）:
- ②: `momentumLookback = 30`, `momentumConfidenceScale = 30`（新②の本番構成）。`horizon=10, k=30, initialEquity=1,000,000`。
- ④: `src/decision-layer/combineSignals.ts` は **main のまま無改変**（VETO=0.5 / CONFIRM=0.3 / BOOST=10 / 高ボラ0.5倍）。
- ③: liveキャッシュ `scripts/data/llm-features-daily.live.json`（source=live, claude-haiku-4-5, 2021-01-01〜2026-07-01）をそのまま注入。プロンプト・モデル・閾値の変更なし。
- フォールド境界・KPI閾値: 既存スクリプトの定義（年次 2021〜、Sharpe+0.2 / DD-3pt）を変更しない。

**(a)を選ぶ理由:**
1. **自由度ゼロ＝過学習不能**。可変パラメータが一つも無いため、選定フォールドで「調整」する余地がなく、全フォールドを確認扱いにできる（prescreen 点2の但し書きに合致）。これが最も反証可能でチェリーピック耐性が高い。
2. **本実験が答えるべき問いは1つ**＝「②の土台が変わっただけで③×④相互作用は改善するか」。過去の失敗は旧②(k-NN)ベース。新②は**方向判定も確信度(z値動的化)も別物**なので、どのフォールドがvetoされ/加点されるかが変わる。まずこの交絡だけを分離して安価($0)に決着させるのが筋。
3. **prescreen 点1・点3の帰結**: 失敗機序は④vetoの過敏（②差替では自動で治らない）と明示されている。ならば④を可変にする(b)は「治療」を混ぜてしまい、③単独の増分と④改修の効果が交絡する。しかも④を可変化した瞬間、選定/確認分離とチューニング停止規律が必要になり、prescreen 点3の「未達なら停止（チューニングに逃げない）」と衝突しやすい。よって本実験は④を凍結し、純粋再測定に徹する。

**参謀官の追加示唆（③を狭い役割＝テール/下落フィルタ限定で使う案）の扱い:**
本実験には**取り込まない**。理由: それは③の「使い方」という自由度の導入であり、(a)の自由度ゼロ設計を壊す。もし本実験(a)が不採用になり、かつ下記「予測単位」測定で③に生エッジが確認された場合に限り、**別OBSとして新規起票**し、選定(2021-2023)/確認(2024-2025)分離を必須にして検証する。本実験のリスコープ（結果を見てからの救済）は禁止。

## 成功 / 不採用の数値基準（回す前に確定）

### パイプライン統合（主ゲート＝採否はここで決まる）
**採用（下記 P1〜P3 を全て満たす）:**
- **P1**: 5フォールド平均 Sharpe差分（③あり − ③なし）**≥ +0.20**
- **P2**: Phase2 KPI（フォールド単位で「Sharpe差分 ≥ +0.2」**または**「最大DD改善 ≥ 3pt」）を満たすフォールドが **≥ 3/5**（単一フォールド勝ち＝チェリーピックを排除）
- **P3**: 最悪フォールドの Sharpe差分 **≥ −0.10**（過去2022年の −1.39 のような大崩れが無いこと）

**不採用（上記のいずれか未達）:**
- 特に **平均Sharpe差分 < +0.20**、または **KPI達成 ≤ 2/5** は即不採用。
- 参考: 旧②ベースの過去実績（平均 −0.33 / 1/5 達成 / 最悪 −1.39）は P1・P2・P3 全て不合格。同水準なら当然不採用。

### 予測単位（診断として必ず測定・報告。主ゲートではない）
③の生シグナル eventImpactScore が、②・④を通さず**単独で**horizon=10日先リターンに直交エッジを持つかを測る。
- **Q1（方向一致）**: `|eventImpactScore| ≥ 0.3` の日について、`sign(eventImpactScore)` と `sign(10日先リターン)` の一致率 **> 50%** かつ permutation p **< 0.05**。
- **Q2（連続IC）**: eventImpactScore と 10日先リターンの Spearman順位相関の符号が**正**、かつ permutation p **< 0.05**。
- **診断ロジック（Cの解釈材料）**: パイプライン不採用 × 予測単位◎ → 主因は④統合（→狭い役割の後続実験を検討）。パイプライン不採用 × 予測単位× → ③シグナル自体に価値なし（→③打ち切りを推奨）。

### kill基準（チューニング逃避の禁止・prescreen 点3の固定）
事前登録した上記(a)構成の下で **パイプライン採用条件 P1〜P3 を満たさない場合、仮説は棄却して不採用で停止する。** その場で ④閾値・vetoロジック・③の使い方・②パラメータを調整して再測定してはならない（HARKing/チューニング逃避）。狭い役割案の再挑戦は本実験のリスコープではなく、選定/確認分離を備えた別OBSの新規起票でのみ許可する。

## 選定 / 確認プロトコル（過学習の炙り出し）
- 本実験は**自由度ゼロ**（可変パラメータなし）のため、選定（探索）フォールドは**存在しない**。
- したがって **5フォールド全て（2021 / 2022 / 2023 / 2024 / 2025）を確認（未見）扱い** とする（prescreen 点2の但し書きに準拠）。どのフォールドも閾値・設定の調整に一切使わない。
