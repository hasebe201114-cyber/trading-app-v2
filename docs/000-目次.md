# ドキュメント目次

本アプリ（trading-app-v2）のドキュメントは、以下の4カテゴリに分類しています。
各カテゴリのフォルダにある `X000-目次.md` から、各ドキュメントへ移動できます。

| カテゴリ | フォルダ | 内容 |
|---------|---------|------|
| A-利用者導入編 | [A-利用者導入編/A000-目次.md](A-利用者導入編/A000-目次.md) | アプリを初めて使う人向けの画面構成・全体の使い方ガイド |
| B-トレーダ向けアプリ活用編 | [B-トレーダ向けアプリ活用編/B000-目次.md](B-トレーダ向けアプリ活用編/B000-目次.md) | バックテスト・フォワードテストなどの実践活用マニュアル |
| C-トレーディング仕様解説編 | [C-トレーディング仕様解説編/C000-目次.md](C-トレーディング仕様解説編/C000-目次.md) | エントリー条件・指標計算・トレード判定ロジック仕様 |
| D-開発者向けシステム仕様編 | [D-開発者向けシステム仕様編/D000-目次.md](D-開発者向けシステム仕様編/D000-目次.md) | UI仕様・システム構成・デプロイ手順 |

## ファイル命名規則

- 目次ファイル: `X000-目次.md`
- 内容ファイル: `X001-ファイル名.md`, `X002-ファイル名.md`, ...（Xは A/B/C/D）

## 開発件名管理（別体系）

開発中の課題・アイデア・対応履歴は、本 `docs` フォルダではなく `obs/trading_app/` 配下の `OBS{6桁}-件名.md` で管理しています
（`01開発アイデア` → `02対応検討中` → `70対応待ち` → `80実装中` → `90解決済` のフォルダ構成）。
