## 4. 重要課題と懸念点

### 4-1. 最重要課題（ブロッキング）

**① F2データの Binance ジオブロック問題（継続注意・非即時ブロッキング）**
- GitHub Actions（米国IP）は Binance Futures API が 451 でブロック → F2ペアが自動蓄積されない
- スクリプト側は graceful skip 実装済み（スクリプト自体は成功する）
- **暫定対策**: PC（非US IP）でのスクリプト手動実行時にBinanceデータが増分マージされる
- **根本対策（day90前に検討）**: A設計チームに参照取引所を OKX 等に変更するかSpec変更を依頼
- **非即時ブロッキング理由**: F2判定は day90 時点のC正式監査。それまでは中間チェックポイントのみ

### 4-2. 非ブロッキング申し送り

| 優先度 | 内容 |
