### 2-4. Fooocus で本番画像を生成

```powershell
# Fooocusを起動
cd C:\Tools\Fooocus
python launch.py
# → ブラウザで http://localhost:7865 を開く
```

`prompts/emotion_prompts.json` を開いて各感情のプロンプトをコピペ。  
生成した画像を `raw_images/` に保存（ファイル名は `sticker_{感情名}.png`）。

**Fooocus推奨設定:**
- Sampler: `DPM++ 2M Karras`
- Steps: `25`
- Guidance: `7.0`
- Size: `512×512`

**最低8枚** 生成してください（スタンプセット要件）。

## 4. トラブル対応

### rembg で背景が残る
```python
# src/batch_process.py の remove_background() 内で
# コントラスト値を 1.5 → 2.0 に上げてみる
enhanced = ImageEnhance.Contrast(img.convert("RGBA")).enhance(2.0)
```

### ファイルサイズが 300KB 超過
- PNG最適化: `pillow` の `optimize=True` オプションで再保存
- またはFooocusのStepsを20に下げて再生成

### LINE申請で「背景が透明でない」と却下された
```python
# 手動チェック
from PIL import Image
img = Image.open("sticker_happy.png")
print(img.mode)          # → RGBA であること
print(img.getextrema())  # → Alpha の min が 0 であること
```
