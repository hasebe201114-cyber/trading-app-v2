## 背景と位置づけ

本提案は外部テクニカルアドバイザー評価（[20260705-外部テクニカルアドバイザー評価-②コア予測エンジンのゼロベース再設計](../85レビュー/20260705-外部テクニカルアドバイザー評価-②コア予測エンジンのゼロベース再設計.md)）§4で提示された「ベース案B」に基づくもの。

**位置づけ**：
- **非価格情報の本命フロンティア**
- OBS000018/022/025/027/028/029/030/031の8連敗は全て「価格由来特徴量から方向を予測する」という族
- **誰も「方向を予測しない」非価格フロー情報を一次シグナルにする設計を、まともに試していない**（③LLM は方向シグナルの補正という使い方だった）
- これが最大の未探索領域

## ベース案B の内容（レビュー要約）

### 何を実装するか
一次シグナルを**非価格のフロー情報**から作る。候補例：

1. **OI×価格のダイバージェンス** ⇒ 
   - 価格↑×OI↑＝健全なトレンド継続
   - 価格↑×OI↓＝ショートスクイズ＝フェード

2. **ファンディング極値の反転シグナル**（キャリーではなく"当てもの"側） ⇒ 
   - ロング過熱→ファンディング急騰→局所天井

3. **清算クラスタ／清算ヒートマップ** ⇒ 
   - 清算カスケード後の反発

4. **CVD（Cumulative Volume Delta）／テイカー買売インバランス、板インバランス** ⇒ 
   - 需給の非対称

### なぜ価値があるか
- **価格由来でない真に直交する情報** ⇒ 8連敗が一度も触れていない領域（③LLM以外の非価格ソース）
- ②モメンタムの**veto/コンディショナーとしても、独立スリーブとしても使える**
- **インフラの一部は OBS000031 Stage 0 で既に構築** ⇒ Bitget の OI・板は取得実績あり

### 正直なリスク・障害

- **履歴深度が浅い** ⇒ OBS000031 Stage 0 で判明：
  - **OI は 2022 未カバー**（無料 API の制限）
  - **清算履歴は HTTP 404**（無料 API 非提供）
  - → **バックテスト深度が浅い ⇒ 有料データ投資が前提** か **フォワード検証が前提**

- **偽陽性温床** ⇒ 
  - フロー指標は自由度が高く過学習しやすい
  - **1指標・1パラメータの事前登録＋held-out 厳守が必須**（OBS000030/031 の教訓）

### 位置づけ

Aより一段**データ投資が要る"次のフロンティア"**。以下の順序を推奨：
1. **Aで低相関スリーブの成功体験と受け皿（配分層 C）を作ってから**着手する
2. 路線別の優先度：
   - **B優先**：OI ダイバージェンス（既存 Bitget OI 取得基盤を活用できる）
   - **B並行**：ファンディング極値反転（Bitget で既に Funding 取得）
   - **B後：**清算反発（無料 API 非提供）・CVD（高頻度・低レイテンシ）
