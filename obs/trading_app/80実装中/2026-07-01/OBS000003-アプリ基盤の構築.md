## 内容
### ルーティング構成
`react-router-dom` で以下の画面遷移を実装（`src/App.tsx`）:
- `/` ホーム、`/patterns` パターン分析、`/signals` シグナル、`/evaluation` 評価、`/settings` 設定

### レイアウト（`src/components/shell/`）
btc-strategyの `AppShell`（デスクトップ=Sidebar、モバイル=TabBarの切替パターン）を参考に、trading-app-v2独自のナビゲーション項目（`navItems.ts`）で作り直した。
- `AppShell.tsx`, `Sidebar.tsx`, `TopBar.tsx`, `MobileTabBar.tsx`

### 状態管理
`@tanstack/react-query` の `QueryClientProvider` を導入済み（既存のuseAuth認証ゲートと統合）。

### CI
`.github/workflows/build.yml` を追加。Firebase未接続のため、現時点は `npm run build` の成功確認のみ実施。Firebaseプロジェクト接続後、firestore rulesデプロイ・hostingデプロイを追加する。

### 動作確認
- `npm run build`（tsc + vite build）成功を確認
- `npm run dev` でdevサーバー起動、Playwrightヘッドレスブラウザでログイン画面の描画・コンソールエラー無し（Google Fontsのネットワークエラーのみ、アプリ起因ではない）を確認
- ログイン後の画面（ホーム/パターン分析等）はFirebaseプロジェクト未接続のため未検証。実プロジェクト接続後に確認要
