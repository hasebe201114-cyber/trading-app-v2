## 実装内容

| ファイル | 役割 |
|---|---|
| `scripts/templates/vrp-backtest-report.html` | レポートのHTMLテンプレート（`__DATA__` / `__GENERATED_AT__` プレースホルダ入り） |
| `scripts/build-vrp-backtest-report.ts` | 生成スクリプト。research JSON + フォワードledgerを読んでHTMLを出力 |
| `public/reports/obs000037-vrp-backtest.html` | 生成物（63KB・自己完結の静的ページ） |
| `src/components/screens/VrpForwardScreen.tsx` | 「バックテストデータ」セクションと導線リンクを追加 |

### 生成方法（再実行）
```
node --experimental-strip-types scripts/build-vrp-backtest-report.ts
```
ハンドコピーではなくスクリプト生成にしたのは、**ライブ較正との接続部の表がledgerの伸長に追従する**ため。
Stage 1のバックテスト系列自体は凍結済みで変化しない。

### レポートの内容
- 全期間の平均VRP +12.56 vol pt（276週・block-bootstrap p=0）、VRP>0週比率 77.2%
- DVOL と 事後実現RV の週次推移（差＝VRPを帯で表示）
- 週次VRPの棒グラフ＋52週移動平均
- **年別の平均VRP**（2021 +22.00 → 2026 +5.96 の減衰。プラス週比率は73〜81%で安定＝崩れているのは頻度でなく厚み）
- 暫定コスト控除後の累積ペイオフ（最大DD 12.37%区間をマーク）
- ライブ較正との接続部（バックテスト末尾4週＋ライブ14点）
- 方法論と限界、週次276点の全数テーブル

### アプリとの統合
- `public/` 配下のためviteがそのまま `dist/` へコピー。Firebase Hostingは実ファイルをSPA rewriteより優先するため、`**` → `/index.html` のrewrite設定のままで配信される
- **テーマはアプリと共有**：`localStorage.theme === 'dark'` を読んで `data-theme` を立てる（`index.html` と同じ判定）。アプリでダークにしていればレポートもダークで開く
- **フォントもアプリと統一**（Inter / Noto Sans JP / JetBrains Mono）
- レポート冒頭とライブ接続部から `/forward?exp=vrp` へ戻る導線あり

## 設計上の判断
- **値の再計算・平滑化・外れ値除去はしない**。生データの転記と描画のみ（スクリプト冒頭にも明記）
- **ライブ接続部は生成時点のスナップショット**であることをページ上に明示し、最新はフォワード較正モニターを見るよう誘導。日次自動更新はしない（司令塔要望「静的で良い」に従い、ワークフローには組み込まない）
- グラフはライブラリ非依存の自前SVG（アプリ本体のバンドルサイズに影響を与えない・レポートは完全に自己完結）
- 配色は既存VRP画面の系統（IV=アンバー / RV=ブルー / VRP=バイオレット）を踏襲しつつ、ライト/ダーク別に
  コントラスト検証済みの階調へ振り分け（青と紫が隣接すると色覚多様性で識別困難になるため、
  同一チャート内で2系列が競合しない構成にしている）
