## 背景
OBS000023でモメンタムを②の後継として採用したが、確信度（Kellyサイジングの入力）はk-NNの「近傍合意率」に相当する概念がないため固定値60を暫定使用していた。全トレードが同じポジションサイズになり、モメンタムの強弱を活かせていなかった。

## 実装（`src/pipeline/simulatePortfolio.ts`）
`momentumConfidenceScale` オプションを追加。指定時は以下でconfidenceを動的算出する:

```
z = |momRet| / (volatility20 × √lookback)   … ランダムウォーク仮定下の標準偏差換算の大きさ
confidence = clamp(50 + scale × z, 50, 95)
```

未指定時は従来どおり固定値60（OBS000020/023との完全互換性を維持、既定OFF）。

## 検証方法（selection→confirmation、OBS000020/023と同一プロトコル）
- 選定: BTCの4期間（2021-2026連続, 2023-2026直近, 2022年, 2023年）でscale∈{5,10,15,20,30}を走査し、固定60との平均Sharpeを比較
- 確認: 選定に使っていないETH（2021-2026連続, 2023-2026直近）でそのscaleを固定適用
- 境界値でないことの確認: scale=30選定後、40/50/70/100も追加で試し、単調に悪化することを確認（極大点であることの傍証）

## 検証結果

### 選定フェーズ（BTC平均Sharpe）
| scale | 平均Sharpe |
|---|---|
| 固定60 | 0.504 |
| 5 | 0.343 |
| 10 | 0.469 |
| 15 | 0.560 |
| 20 | 0.616 |
| **30** | **0.665** |
| 40（追加確認） | 0.646 |
| 50（追加確認） | 0.618 |
| 70（追加確認） | 0.594 |
| 100（追加確認） | 0.564 |

scale=30が極大（30を挟んで両側で悪化）。境界値の見かけの最良ではなく真の最適点と確認。

### 確認フェーズ（ETH・未見データ）
| 期間 | 固定60 | scale=30 |
|---|---|---|
| ETH 2021-2026連続 | Sharpe0.44 | **Sharpe0.91** |
| ETH 2023-2026直近 | Sharpe0.29 | **Sharpe0.67** |

選定に一切使っていないETHの両期間で、scale=30が固定60を明確に上回った（合計Sharpe 0.73→1.58）。

### 留保点
BTC 2022年（弱気相場）はscale=30でもSharpe-0.14と固定60(0.19)を下回る。動的化は「強いトレンドに乗る」設計のため、方向感の乏しい下げ相場ではやや不利になる可能性がある。ただし他の3期間・ETH確認2期間すべてで改善しており、全体としては採用が妥当と判断。

## 結論
**モメンタムの確信度動的化（z値ベース、scale=30）を採用する。** BTCで選定した値がETHの未見データでも一貫して改善したことから、過最適ではなく実質的な改善と判断できる。ただし弱気相場(BTC2022年)ではやや不利になる留保点があり、今後の改善余地として記録する。

## ERゲートとの組み合わせ検証（2026-07-04, scripts/momentum-er-gate-validation.ts）

BTC2022年の弱点を緩和できるか、適応的ERゲート(OBS000018)をモメンタム(L=30,scale=30)に組み合わせて検証した。

### 選定フェーズ（BTC平均Sharpe）
| 設定 | 平均Sharpe |
|---|---|
| モメンタムのみ | **0.665** |
| +ERゲート(warmup20) | 0.274 |
| +ERゲート(warmup30) | 0.604 |
| +ERゲート(warmup40) | 0.648 |
| +ERゲート(warmup50) | 0.604 |

**BTC2022年単体は改善**（モメンタムのみSharpe-0.14 → +ERゲート(warmup50)で+0.14）。狙い通りレンジ局面のポジションを間引くことで弱点は緩和できた。しかし2021-2026連続・2023年など他の期間でSharpeが下がり、**4期間平均ではモメンタム単体(0.665)がいずれのwarmupも上回った**（最良のwarmup40でも0.648）。

### 結論
ERゲートは「狙った弱点（BTC2022年）」には効くが、「全体としての改善」にはならない。これはOBS000018で確認した「ERゲートは特定局面を守る代わりに他局面の機会損失を生み、ポートフォリオ水準では正味の改善にならない」というパターンと一致する。**組み合わせは不採用とし、モメンタム単体(確信度動的化のみ)を維持する。**
